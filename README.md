# 📊 Retail Customer Behavior Analysis

## 🔹 Overview
This project focuses on analyzing retail customer behavior and shopping trends using Python, SQL, and Power BI to generate actionable business insights.

## 🔹 Tools & Technologies
- Python (Pandas, NumPy)
- SQL (PostgreSQL)
- Power BI
- Jupyter Notebook

## 🔹 Key Features
- Data cleaning and preprocessing
- Exploratory Data Analysis (EDA)
- SQL-based data querying
- Interactive Power BI dashboard

## 🔹 Insights
- Identified customer purchasing patterns  
- Analyzed product performance trends  
- Provided data-driven business recommendations  

## 🔹 Outcome
This project demonstrates the ability to work with real-world datasets and convert raw data into meaningful insights for decision-making.
